# kaptein

The Kaptein CLI — a thin command-line projection of the shared view-model. It drives
`kaptein-core` directly and exposes governed read-only access (list/describe/logs/events/
overview), RBAC preflight, diagnostics, lens validation/rendering, a read-only MCP
server, and a dry-run-gated write path.

See the [Kaptein repository](https://github.com/egkristi/Kaptein) for the full
architecture, roadmap, and license terms (BUSL-1.1, converting to MIT on the Change
Date).
