# frontend-tui

The ratatui terminal frontend. It renders a render-intent (columns, rows, actions,
status) produced by `kaptein-viewmodel` — it never computes meaning, only geometry
(column width, scroll, focus, hover).

See the [Kaptein repository](https://github.com/egkristi/Kaptein) for the full
architecture, roadmap, and license terms (BUSL-1.1, converting to MIT on the Change
Date).
